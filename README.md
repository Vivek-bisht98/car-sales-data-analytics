# 🚗 Car Sales Analytics Dashboard

## 📊 Project Overview

This project is an interactive **Car Sales Analytics Dashboard** built using **Microsoft Power BI**. The goal of the project is to analyze car sales data and present important sales metrics, trends, and performance insights through an easy-to-use dashboard.

The dashboard consists of **two interactive pages**:

- **Dashboard** – Provides a high-level overview of car sales performance.
- **Details** – Provides a more detailed view of the underlying sales data and analysis.

---

## 🎯 Objectives

The main objectives of this project are to:

- Analyze overall car sales performance.
- Identify sales trends over time.
- Compare sales performance across different categories.
- Analyze important sales metrics and KPIs.
- Present data in an interactive and visually appealing format.
- Make business insights easier to understand through data visualization.

---

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and analytics
- **Data Visualization**
- **Data Analysis**

## 📌 Dashboard Pages

### 1. Dashboard

The main dashboard provides an overview of car sales performance using interactive visualizations and KPI cards.

It helps users quickly understand:

-Sales Overview
-Average Price Analysis
-Cars Sold Metrics
-YTD Sales Weekly Trends
-YTD Total Sales by Body Style
-YTD Total Sales by Color
-YTD Cars Sold by Dealer Region
-Company wise Sales Trend in Grid

### 2. Details

The Details page provides a more granular view of the sales data.
── Details Grid Showing All Car Sales Information 
It allows users to explore the data in greater detail and understand the factors contributing to overall sales performance.
